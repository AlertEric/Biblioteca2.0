# 🔥BIBLIOTECA-README🔥

## Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido com o objetivo de estudar, praticar e consolidar conhecimentos em desenvolvimento Back-End, 
aplicando conceitos de programação orientada a objetos e persistência de dados na construção de um 
sistema de gerenciamento de biblioteca.

O projeto busca demonstrar conhecimentos nas seguintes tecnologias e ferramentas:

* Java — desenvolvimento da lógica de negócio.
* POO (Programação Orientada a Objetos) — aplicação de classes, objetos, encapsulamento, herança e polimorfismo.
* Spring Boot — estruturação e desenvolvimento da aplicação.
* Spring Data JPA e Hibernate — mapeamento objeto-relacional e persistência de dados.
* SQL — consultas e manipulação de dados.
* Oracle e MySQL — bancos de dados relacionais.
* Git e GitHub — versionamento de código e gerenciamento do projeto.
* Docker — conteinerização e organização do ambiente de desenvolvimento.

O projeto está em constante evolução e tem como propósito aprofundar meus conhecimentos em desenvolvimento Back-End com
Java e o ecossistema Spring.

##  _Configurações para roda o sistema:_

* [JAVA](https://download.oracle.com/java/21/latest/jdk-21_windows-x64_bin.exe) JDK 21(Configurar váriavel de ambiente)
* MAVEN(Gerenciar as estruturas do codigo, dependencias e spring)
* Drive [JDB](https://learn.microsoft.com/pt-br/sql/connect/jdbc/download-microsoft-jdbc-driver-for-sql-server?view=sql-server-ver17)

### _Dependencias:_
* Spring Boot
* Spring Data JPA
* mySQL
